## 1. COMPLETE PRODUCT SPECIFICATION

### 1.1 Objective & Target Use
Hexatron is a dedicated desktop and mobile web application built for authors, narrative designers, and worldbuilders who maintain sprawling fictional universes with intricate political, dynastic, cultural, and geographical lore.

It combines:
1. **Wikipedia/Obsidian-Style Encyclopedia**: Rich-text lore articles with wikilinks, backlink detection, and structured metadata.
2. **Cosmological & Geographical Hierarchy**: A rigorous 8-level cosmological nesting model (`Universe -> Galaxy -> Solar System -> Planet -> Continent -> Nation -> Governorate/State -> Settlement/City`). Nations are never conflated with planets or worlds; multiple sovereign nations coexist on continents.
3. **Permanent Chronological Entry Numbers (#001–#999+)**: Every entity has an immutable entry number assigned at creation that remains fixed regardless of alphabetical sorting, editing, or deletion of other entities.
4. **First-Class Relational Spiderweb Graph**: Interactive force-directed network graph visualizing alliances, enmities, administrative authority, kinship, and historical ties with scope filters, category filters, and selection highlighting.
5. **Categorized Linked Entities**: Right-hand contextual panel grouping an article's incoming and outgoing links by category (Cosmology, Administration, Settlements, Politics & Economics, Peoples & Faith, History).
6. **Family Tree & Succession Visualizer**: Dedicated generator rendering kinship networks and generational succession.
7. **Self-Describing Backup & Recovery**: Version 2 `.json` backup system with validation engine, non-destructive Merge mode, and clean atomic Restore mode.
8. **Local-First Zero-Latency Storage**: Primary data resides in browser IndexedDB (Dexie.js), with optional cloud sync to Supabase.

## 2. DATA MODEL & SCHEMA SPECIFICATION

The application utilizes IndexedDB via **Dexie.js** with database name `hexatron`. All records must adhere to the following TypeScript interfaces:

```typescript
// --- Cosmological & Geographical Hierarchy Types ---
export type HierarchyLevel =
  | 'universe' | 'galaxy' | 'solar-system' | 'planet' | 'continent'
  | 'nation' | 'governorate' | 'state' | 'territory' | 'city' | 'settlement';

// --- Canon Status ---
export type CanonStatus = 'canon' | 'in_progress' | 'disputed' | 'apocrypha';

// --- Database Records ---

export interface Universe {
  id: string;             // UUIDv4
  title: string;          // e.g., "Universe of Aurythar"
  description?: string;
  createdAt: number;
  updatedAt: number;
}

export interface World {
  id: string;             // UUIDv4
  universeId: string;     // Foreign key to Universe.id
  title: string;          // e.g., "Aurythar"
  description?: string;
  color?: string;         // Hex accent color (e.g., "#3b82f6")
  icon?: string;          // Lucide icon name (e.g., "Globe")
  createdAt: number;
  updatedAt: number;
}

export interface PropertyFieldDef {
  key: string;            // e.g., "capital", "population", "climate"
  label: string;
  type: 'text' | 'number' | 'date' | 'select' | 'entity_ref';
  options?: string[];
  required?: boolean;
}

export interface EntityType {
  id: string;             // e.g., "et-character", "et-nation", "et-continent", "et-city"
  name: string;
  color: string;
  icon: string;           // Lucide icon name
  description?: string;
  isBuiltIn: boolean;
  defaultFields?: PropertyFieldDef[];
}

export interface Entity {
  id: string;             // Immutable UUIDv4
  worldId: string;        // Foreign key to World.id
  typeId: string;         // Foreign key to EntityType.id
  title: string;          // Primary title (e.g., "Federated States of Aurythar")
  entryNumber?: number;   // Permanent sequential integer (#001, #002, etc.)
  aliases: string[];      // Alternate names, acronyms (e.g., ["FSA", "Federation"])
  article?: string;       // Serialized TipTap ProseMirror JSON doc string
  properties?: Record<string, unknown>; // Custom key-values (governmentType, capital, etc.)
  tags: string[];
  canonStatus: CanonStatus;
  linkedEntityIds: string[]; // Denormalized target entity IDs mentioned in article
  createdAt: number;
  updatedAt: number;
  deletedAt?: number;
}

export interface RelationshipType {
  id: string;             // e.g., "rt-capital-of", "rt-governs", "rt-citizen", "rt-parent"
  name: string;           // Outgoing label (e.g., "capital of", "governs", "citizen of")
  reverseName: string;    // Incoming label (e.g., "capital is", "governed by", "has citizen")
  color: string;
  isBuiltIn: boolean;
}

export interface Relationship {
  id: string;             // UUIDv4
  fromEntityId: string;   // Foreign key to Entity.id
  toEntityId: string;     // Foreign key to Entity.id
  typeId: string;         // Foreign key to RelationshipType.id
  worldId: string;        // Foreign key to World.id
  canonStatus: CanonStatus;
  dateStart?: string;
  dateEnd?: string;
  notes?: string;
  createdAt: number;
  updatedAt: number;
  deletedAt?: number;
}

export interface EntityImage {
  id: string;             // UUIDv4
  entityId: string;       // Foreign key to Entity.id
  role: 'avatar' | 'banner' | 'gallery' | 'map';
  caption?: string;
  localBlob?: Blob;       // Stored locally in IndexedDB
  remotePath?: string;    // Remote URL if synced
  width?: number;
  height?: number;
  mimeType?: string;
  sortOrder: number;
  createdAt: number;
}
```

## 3. CORE BEHAVIOR & BUSINESS RULES

1. **Stable Internal IDs vs. Permanent Entry Numbers**:
   - `id`: Internal UUIDv4 used as foreign keys across relationships, image links, and backlinks.
   - `entryNumber`: Human-facing sequential integer (`#001` - `#999+`) assigned at creation. Once assigned, it is NEVER modified, reused, or shifted.
2. **Geographical & Cosmological Invariants**:
   - Multiple nations must be able to belong to the same continent (e.g., FSA, Grand Duchy of Valais, Kingdom of Oakhaven on Continent of Aurythar).
   - Administrative divisions (Governorates, States, Territories) belong to a Nation.
   - Settlements (Cities, Towns) belong to a State/Governorate and/or Nation.
   - The hierarchy is maintained via first-class relationships:
     - `Planet Aurythar` --[contains]--> `Continent of Aurythar`
     - `Continent of Aurythar` --[contains]--> `Federated States of Aurythar`
     - `Federated States of Aurythar` --[governs]--> `Governorate of Aurythar Central`
     - `State of Eldoria` --[capital is]--> `City of Eldoria`
3. **No Hallucinated Lore or Silent Changes**:
   - An entity must never be created or altered with invented facts.
   - Competing historical claims or conflicting figures must be preserved as separate `et-theory` entities or flagged under `canonStatus: "disputed"`.
4. **Safe Cascading Deletions**:
   - Deleting a World must delete all child entities, relationships, and images belonging to that world.
   - Deleting a Universe must cascade through all child worlds and their entities.
   - Deletions must require explicit modal confirmation showing exact counts of child records to be erased.
5. **Graph Radius Bounding & Performance**:
   - Node radii must be mathematically bounded between `9px` and `22px` regardless of connection count.
   - Force simulation must stop computing physics when `alpha < 0.005`.
   - Dim unrelated nodes (`opacity: 0.22`) when a node is selected.
